# 거래소 프로젝트 등록

- 표시명: 거래소 (작성자 지정), 공식 사이트 명칭: REOWN
- 배포: https://reown-eight.vercel.app/
- 중고 물품 거래 프로젝트이며 금융자산 거래소나 모의 투자 서비스가 아닙니다.
- 공개 화면에서 상품 탐색·검색·분류·정렬·지역 선택 UI를 확인했습니다. 실결제 운영 여부는 확인되지 않았으며 안전거래 안내는 준비 중입니다.
- 작성자 제공: 기간 9월~12월(연도 미확인), 백엔드 개발, React·Next.js·MongoDB, MongoDB 첫 연동 경험.
- 로컬 참고 저장소 `../reown`의 README는 학교 5인 팀 프로젝트로 설명합니다. 참고 소스에는 Vite·Express·PostgreSQL 구성도 있어, 작성자가 제공한 기술 정보와 동일한 버전이라고 단정하지 않습니다.
- API 설계·인증·거래 처리·스키마 설계 등 구체적인 개인 기여와 GitHub 주소는 확인되지 않아 추가하지 않았습니다.
- 썸네일은 로그인하지 않은 공개 홈을 캡처한 실제 화면입니다.

## MongoDB

`.env.local`의 서버 전용 `MONGODB_URI`와 선택 설정 `MONGODB_DB`를 사용합니다. DB 기본값은 `portfolio`, 컬렉션은 `projects`입니다. 연결 문자열은 클라이언트로 전달하지 않습니다.

```sh
npm run seed:reown
```

`data/reown-project.json`을 slug 또는 정규화된 배포 주소로 upsert합니다. 기존 ID와 정렬 순서를 유지하며 slug·배포 주소의 유일 인덱스로 중복 생성을 막습니다. 여러 기존 항목이 동시에 일치하거나 ID 충돌이 있으면 자동 삭제·병합하지 않고 실패합니다. 오류 로그에 접속 정보를 출력하지 않습니다.

홈과 프로젝트 상세는 서버에서 공개 프로젝트를 읽고 기존 로컬 3개 프로젝트와 정렬 순서대로 합칩니다. DB가 연결되지 않으면 로컬 카탈로그를 대체 데이터로 사용하며, 이는 DB 등록 완료를 의미하지 않습니다.

검증: `node scripts/verify-orb.mjs --stage=16 --only` (실행 중인 로컬 서버 필요).
