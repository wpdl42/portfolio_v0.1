# portfolio_v0.1

정보보호학과 2학년 개인 포트폴리오의 첫 번째 버전입니다.

Next.js App Router와 TypeScript를 사용해 프로젝트, 과제, 학습 진행 상황을 정리합니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 페이지 구성

- `/` 소개 및 주요 프로젝트
- `/projects` 프로젝트 목록
- `/assignments` 수업 과제 목록
- `/progress` 기술 학습 진행 상황

현재는 중간 과제용 기본 구조이며, 기말까지 프로젝트 상세 내용과 서버 기능을 추가할 예정입니다.
